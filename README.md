## 🌟 Overview

**My AI Workspace** is a clean, responsive, and modern personal dashboard designed with a dark charcoal theme and electric blue/vivid violet accents. Built with standard HTML5, CSS3, and modern vanilla JavaScript, it runs instantly in any browser without requiring `npm`, complex builds, or external backend setup.

## 🧪 How to Test the PDF Links

You can test the clickable PDF links across your workspace in three simple ways:

### 1. Test from the Knowledge Base Section (`index.html#knowledge-base`)
1. Open [`index.html`](file:///c:/Users/urvas/Documents/my%20ai%20workspace/index.html) in your browser.
2. Scroll to the **Knowledge Base** section.
3. Every card now displays the real assignment PDF file:
   - Click the blue **"Open PDF"** button next to any item.
   - Your browser (Chrome, Edge, Brave, or Firefox) will immediately open the PDF document in a new tab using its native built-in PDF viewer.
   - You can also click the copy icon button next to it to copy the exact file path to your clipboard.

### 2. Test from the Projects Tracker Section (`index.html#projects`)
1. Scroll down to the **Projects Tracker** section.
2. For Builds 1 through 5, you will see the exact file path prefilled in the project link field (e.g. `knowledge base/build_1_ai_tools_comparison.pdf.pdf`).
3. Click the blue **"Open PDF"** button next to the input field.
4. The assignment PDF will open in a new browser tab.
5. You can also edit the status dropdown or change the link at any time and click **"Save"**.

### 3. Test from the Portfolio Showcase Page (`portfolio.html`)
1. Click **"Portfolio Showcase →"** in the top navigation bar (or open `portfolio.html`).
2. Scroll through the six build cards.
3. Each completed or in-progress build card contains a direct **"View PDF"** button that opens the real PDF.

> [!TIP]
> **Why relative paths work smoothly**: The links use relative paths like `knowledge base/build_1_ai_tools_comparison.pdf.pdf`. Because the `knowledge base` folder lives directly inside the workspace folder alongside `index.html` and `portfolio.html`, these links work instantly both offline (via `file:///`) and on local web servers.
